# 手部相机方向

参考模型的 `end_camera` 位于 `grip_base_link` 局部坐标 `(0.066, 0, 0.105)`，原始四元数为 `(0.8660254, 0, -0.5, 0)`，视场角 50°。

MuJoCo 相机的局部 -Z 是观察方向，+Y 是画面上方。在可达观察姿态 `q=[0,-0.579,2.723,-0.573,0,0]` 下，原始光轴指向工作区，但画面滚转使桌面呈现为竖直方向。

校正只改变绕光轴的滚转，不改变相机位置、视场角或光轴。新局部四元数为：

```text
0.6123724 0.3535534 -0.3535534 -0.6123724
```

校正后，约定观察姿态中世界 +Z 朝画面上方，世界 +Y 朝画面右侧。该结果由临时方向标记渲染验证；临时标记不包含在默认场景中。对照图位于 `artifacts/camera_before.png` 与 `artifacts/camera_after.png`。

这落实的是“画面在桌面观察姿态下正立”，不是把相机改成沿 TCP +X 观看。

## 固定左后方相机

新增 `left_rear`（模型名 `left_rear_camera`），固定于 world `[-0.65, 0.85, 1.15]`，朝向桌面中心 `[0.5, 0, 0.32]`，fovy 60°。机器人前方定义为 +X，左侧为 +Y，因此 −X/+Y 为左后方。渲染验证可见机械臂、桌面、绿色目标区及红色物块。与手部相机一样支持默认 224×224 RGB 和毫米深度，并通过共享快照提供最新已发布图像。两路渲染依次执行，会增加每轮渲染耗时。

```bash
mujoco_cli image get --camera left_rear --output artifacts/left_rear.png
```
