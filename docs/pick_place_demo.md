# 夹块演示

终端一启动 GUI 服务（代码更新后请重启服务）：

```bash
mujoco_server --config configs/default.yaml
```

终端二执行：

```bash
.venv/bin/python scripts/pick_place_demo.py
```

流程：记录初始关节 → 开爪 → 查询物块 → 末端移动到接近点及抓取点 → 闭爪 → 抬升、运输、下降 → 开爪 → 撤离并回到初始关节。脚本不重置环境、不设置物块位置。失败时停止并保留现场。

## 位姿约定

TCP 朝向固定为绕世界 Y 轴倾斜 45°，wxyz 四元数 `[0.9238795325, 0, 0.3826834324, 0]`。TCP +X 沿世界 +X/−Z 方向斜向下 45°，+Y 为夹爪开合方向。物块查询只使用 `position`，不使用物块四元数计算末端朝向；接近、抓取、抬升、运输、释放和撤离的朝向均保持该固定值。

夹爪指腹在 TCP 的局部 −X 侧。通过模型网格检查确定局部偏置方向，并实测默认抓取偏置 `[0.015, 0, 0.0016]`（米）；它表示“物块中心到 TCP 的向量，在 TCP 坐标轴中表达”。计算公式为：

```text
TCP世界位置 = 物块世界位置 + R_world_tcp × 局部偏置
```

固定 45° 朝向下，偏置旋转到世界约为 `[0.01174, 0, -0.00948]` m，不能直接用固定的世界 Z 正偏置替代。模型指腹的可用位置随夹爪闭合角变化，默认值是对当前 4 cm 方块验证过的抓取参数，不是通用标定值。

`--target` 现在指期望释放时的**物块中心世界坐标**，默认 `[0.6, 0, 0.332]`。抬升和运输后查询物块与 TCP 的实际相对位置，再计算释放 TCP，避免初始抓取偏置误差传播到放置位置。

```bash
.venv/bin/python scripts/pick_place_demo.py --target 0.6 0 0.332 --grasp-offset 0.015 0 0.0016 --clearance 0.12 --timeout 20
```

demo 不提供 `--quaternion` 参数，末端朝向为固定值。当前参数针对参考场景初始方块位置和姿态；不保证任意旋转方块、任意初始机械臂姿态均可成功。

## 验证

EGL headless 的固定 45° 朝向完整七步实测通过：抬升后物块约 `[0.5023, -0.0019, 0.4464]`，运输后约 `[0.5997, 0, 0.4458]`，释放落稳后约 `[0.60025, 0.00091, 0.32200]`，随后机械臂返回初始关节。全过程没有设置物块位姿。

末端控制在独立 MjData 上求带关节限位的完整逆解后执行；模型原有 equality 约束用于手指联动，不再强制覆盖手指 qpos。抬升/运输后的高度检查及落稳检查用于拒绝空夹、掉落或悬空的假成功。

独立验证脚本 `scripts/run_pick_place_demo.py` 会在独立端口启动 headless 服务，不连接或修改已有 GUI 服务。GUI 模式的窗口交互效果尚未单独验收。
